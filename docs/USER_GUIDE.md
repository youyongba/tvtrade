## 系统概述

TVTrade 是一个连接 TradingView 和加密货币交易所的自动交易系统。通过 TradingView 的警报功能发送 Webhook，系统自动执行开仓、止盈、止损等交易操作。

### 支持的交易所

- ✅ Binance Futures（币安合约）
- 🚧 OKX（开发中）
- 🚧 Bybit（开发中）
- 🚧 Bitget（开发中）

### 核心特性

- 📊 分批开仓：支持多个入场点位
- 🎯 多级止盈：设置多个止盈目标
- 🛡️ 保护性止损：首次止盈后自动在开仓价挂止损单保护本金
- 🔄 防重复触发：每个止盈/止损只执行一次，适配 TradingView 每根 K 线触发

## 快速开始

### 1. 注册登录

1. 访问系统首页
2. 点击右上角登录按钮
3. 首次使用选择"注册"，填写用户名、邮箱、密码
4. 注册成功后自动登录

### 2. 配置交易所 API

1. 点击页面顶部的"交易所: 未连接"
2. 选择交易所（如 Binance）
3. 填入 API Key 和 API Secret
4. 点击"测试连接"验证
5. 连接成功后点击"保存配置"

### 3. 创建交易配置

1. 在左侧面板选择交易对（如 BTCUSDT）
2. 选择方向：做多 / 做空
3. 设置杠杆倍数
4. 配置开仓、止盈、止损参数
5. 点击"保存配置"

### 4. 设置 TradingView 警报

1. 复制系统生成的 Webhook JSON
2. 在 TradingView 创建警报
3. 将 Webhook URL 和 JSON 消息填入
4. 激活警报

## 交易所配置

### 获取 Binance API

1. 登录 [Binance](https://www.binance.com)
2. 进入 **用户中心 → API 管理**
3. 创建新的 API Key
4. 开启权限：
   - ✅ 启用合约交易
   - ✅ 允许读取
   - ❌ 不要开启提现权限
5. 设置 IP 白名单（推荐）

### 配置说明

| 字段 | 说明 |
|------|------|
| API Key | 交易所提供的 API 密钥 |
| API Secret | 交易所提供的 API 密钥（加密存储） |
| Passphrase | 部分交易所需要（如 OKX） |

### 测试连接

点击"测试连接"后，系统会：
1. 验证 API 密钥有效性
2. 获取账户余额
3. 检查交易权限

## 创建交易配置

### 基本设置

```
交易对: BTCUSDT
方向: 做多 / 做空
杠杆: 1x - 125x
```

### 开仓配置

支持分批开仓，每个开仓点位独立配置：

| 参数 | 说明 | 示例 |
|------|------|------|
| 仓位比例 | 使用余额的百分比 | 30% |
| 订单类型 | 市价 / 限价 | 市价 |

**添加多个开仓点**：点击"+ 添加开仓"按钮

### 止盈配置

支持多级止盈，逐步锁定利润：

| 参数 | 说明 | 示例 |
|------|------|------|
| 平仓比例 | 平掉持仓的百分比 | 50% |
| 订单类型 | 市价 / 限价 | 市价 |

**示例策略**：
- 止盈1: 平 50% 仓位
- 止盈2: 平 100% 仓位（剩余全部）

### 止损配置

| 参数 | 说明 | 示例 |
|------|------|------|
| 平仓比例 | 平掉持仓的百分比 | 100% |
| 订单类型 | 市价 / 限价 | 市价 |

### 保护性止损（重要）

启用后，当**第一个止盈触发**时，系统会自动在**开仓价**挂一个止损单，保护剩余仓位的本金。

**工作流程**：
```
开仓 $100,000
    ↓
价格上涨，止盈1触发（平50%仓位，盈利 $500）
    ↓
自动在开仓价 $100,000 挂止损单
    ↓
情况A: 价格继续上涨 → 止盈2触发，完美退出
情况B: 价格回落到开仓价 → 止损触发，保本退出（不亏钱）
```

## TradingView 警报设置

### Webhook URL

在系统侧边栏找到 **Webhook URL**，格式如：
```
https://your-domain.com/webhook/YOUR_TOKEN
```

### 警报消息格式

系统会自动生成每个操作的 JSON 消息，直接复制使用。

#### 开仓消息示例

```json
{
  "token": "your-webhook-token",
  "action": "open_long",
  "symbol": "BTCUSDT",
  "leverage": 100,
  "position_size": "30%",
  "order_type": "market",
  "entry_index": 1,
  "timestamp": "{{timenow}}"
}
```

#### 止盈消息示例（带保护性止损）

```json
{
  "token": "your-webhook-token",
  "action": "take_profit",
  "symbol": "BTCUSDT",
  "close_percent": "50%",
  "order_type": "market",
  "trigger": "tp_1",
  "timestamp": "{{timenow}}",
  "set_protection_sl": true,
  "protection_sl_price": "entry_price",
  "protection_sl_order_type": "market"
}
```

#### 止损消息示例

```json
{
  "token": "your-webhook-token",
  "action": "stop_loss",
  "symbol": "BTCUSDT",
  "close_percent": "100%",
  "order_type": "market",
  "trigger": "sl_1",
  "timestamp": "{{timenow}}"
}
```

### TradingView 设置步骤

1. 在 TradingView 图表上设置你的交易条件
2. 右键点击 → 添加警报
3. 条件设置为你的入场/出场信号
4. 选择 **Webhook URL**
5. 填入系统提供的 Webhook 地址
6. 在消息框粘贴对应的 JSON
7. 设置触发频率：**每根 K 线一次**（推荐）
8. 保存警报

### 触发频率说明

推荐设置为"每根 K 线执行一次"，因为系统有防重复触发机制：

- ✅ 没有持仓时，止盈/止损信号会被跳过（不报错）
- ✅ 已触发过的止盈/止损不会重复执行
- ✅ 开仓后，止盈/止损才会真正执行

## 持仓管理

### 当前持仓

显示所有活跃持仓的实时信息：

- 交易对和方向（LONG/SHORT）
- 杠杆倍数
- 开仓价格 / 当前价格
- 持仓数量 / 保证金
- 未实现盈亏（实时计算）
- 交易状态（已触发的止盈/止损）

### 操作按钮

| 按钮 | 功能 |
|------|------|
| 🔄 同步 | 刷新当前价格和盈亏 |
| ↻ 重置 | 重置触发状态，允许止盈/止损再次触发 |
| 平仓 50% | 市价平掉一半仓位 |
| 全部平仓 | 市价平掉全部仓位 |

### 交易状态

| 状态 | 说明 |
|------|------|
| ⏳ 等待触发 | 还没有止盈/止损被触发 |
| ✓ 止盈1 | 止盈1已触发 |
| ✓ 止损1 | 止损1已触发 |
| 🛡️ 保本止损 | 保护性止损已挂单 |

### 重置功能

**使用场景**：
- 止盈1已触发，但你想让它再次可触发
- 保护性止损被触发后，想重新开始

**操作**：点击"↻ 重置"按钮，确认后所有触发状态清空。

## 重要功能说明

### 防重复触发机制

系统会记录每个持仓已触发的止盈/止损：

```
位置数据:
- triggeredTPs: [1]      // 止盈1已触发
- triggeredSLs: []       // 止损未触发
- protectionSLPlaced: true  // 保护性止损已挂
```

当 TradingView 再次发送相同的止盈信号时：
- 系统检测到"止盈1已触发"
- 返回成功但不执行交易
- 终端日志：`⏭️ 跳过: 止盈 1 已触发过，不重复执行`

### 没有持仓时的处理

如果收到止盈/止损信号但没有对应持仓：
- 系统返回成功但不执行
- 不会报错
- 终端日志：`⏭️ 跳过: 没有 BTCUSDT 持仓，不执行 take_profit`

这样你可以在 TradingView 设置"每根 K 线触发一次"，系统会自动过滤无效信号。

### 数量精度处理

系统自动处理各交易所的数量精度要求：
- 自动获取交易对的精度信息
- 下单数量向下取整
- 确保不小于最小下单量

## 常见问题

### Q: 为什么盈亏显示 $0.00？

**A**: 点击"🔄 同步"按钮刷新实时价格。如果仍然为 0，检查：
- 交易所是否已连接
- API 是否有读取权限

### Q: 止盈没有触发怎么办？

**A**: 检查以下几点：
1. 是否有对应的持仓
2. 该止盈是否已经触发过（查看交易状态）
3. TradingView 警报是否正确设置
4. Webhook URL 是否正确

如果止盈已触发过，点击"↻ 重置"可以重新允许触发。

### Q: 保护性止损没有挂上？

**A**: 确认以下条件：
1. 在配置中勾选了"止盈触发后挂保护性止损"
2. 只有**第一个止盈**会触发保护性止损
3. 止盈后还有剩余仓位（不是全部平仓）

### Q: 如何修改已保存的配置？

**A**: 
1. 在"已保存配置"中点击要修改的配置
2. 修改参数
3. 点击"保存配置"覆盖保存

### Q: 关闭浏览器后还能自动交易吗？

**A**: ✅ 是的。系统运行在服务器端，只要服务器在运行：
- TradingView 发送 Webhook
- 服务器接收并执行交易
- 不需要打开浏览器

### Q: API Key 安全吗？

**A**: 
- API Secret 使用 AES-256 加密存储
- 建议只开启交易权限，不开启提现权限
- 建议设置 IP 白名单
